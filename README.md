# Merge Boxes! 2D
**Merge Boxes! 2D** is a cozy merge incremental game where you build your very own box collection.

It is a sequel to [Merge Boxes!](https://www.roblox.com/games/15795590655/Merge-Boxes), my old game on ROBLOX, reimagined as a 2D incremental game.
The game is still in development, so features, content, and mechanics may change or be incomplete.

## Open Source

**Merge Boxes! 2D** is open source and available to read, modify, and learn from.
The game is developed using [LÖVE2D](https://love2d.org/).
