# Merge Boxes! 2D
**Merge Boxes! 2D** is a cozy merge incremental game where you build your very own box collection.

It is a sequel to [Merge Boxes!](https://www.roblox.com/games/15795590655/Merge-Boxes), my old game on ROBLOX, reimagined as a 2D incremental game.
The game is still in development, so features, content, and mechanics may change or be incomplete.

The amount of content planned for this game is quite large, but I think I can handle it.
This project has been in development on and off since December 13th, 2025.

## Open Source
**Merge Boxes! 2D** is open source and available to read, modify, and learn from.
The game is developed using [LÖVE2D](https://love2d.org/).

## How to run the game?
Dedicated support for Linux and macOS is planned for the future, but for now, you'll have to run the source code manually on those platforms.

For Linux and macOS, download the source code from the [releases page](https://github.com/mellowestmel/Merge-Boxes-2D/releases), as the `main` and `dev` branches may be unstable.

### Windows
1. Download the latest release.
2. Extract it.
3. Run `play.exe`.

### Linux
1. Install [LÖVE2D](https://love2d.org/).
2. Extract the source code.
3. Open a terminal in the extracted directory.
4. Run `love .`.

### macOS
1. Install [LÖVE2D](https://love2d.org/).
2. Extract the source code.
3. Open Terminal and navigate to the extracted directory.
4. Run `open -n -a love "$PWD"`. (Note that this command might not work on every Mac. Sorry not sorry, I do not own or plan on owning a Mac.)
